VOICE TESTS FOR THE NEW COMMANDS (DAV)
==============================================

What this is: a list of what needs to be tested with your own voice. Everything below was
verified with simulated voice answers (in FreeCAD 1.1 headless), but voice
recognition and the real dialogs were NOT tested.

How to use the list: say it, watch what happens and mark [x] if it worked. If the recognizer
hears something else, note what it heard: it helps to add synonyms.

Before you start
  - FreeCAD with the DAV panel, Spanish language, new document.
  - If you get lost: "contexto" (context). To go up a level: "subir" (go up). To abort: "cancelar" (cancel).
  - Numbers: "ochenta enter" (eighty enter). Decimals: "uno coma cinco" (one point five). Hundreds are said digit
    by digit ("uno cero cinco" = 105).
  - The path of each command = what you have to say from the main menu.

SETUP (only once, serves for almost all tests)
------------------------------------------------------------------------------
Create a document with 3 objects with different names so they can be searched for:
  1. banco de trabajo -> diseño de pieza -> aditivo -> cilindro por medidas
     (workbench -> part design -> additive -> cylinder by size)
     "diez enter" "veinte enter" "cero enter" "cero enter" "cero enter" "si"
     (body "Body")
  2. Repeat with other dimensions: "cinco" "ocho" "cuarenta" "cero" "cero" "si"
     (body "Body001")
  3. A third part: "veinte" "cuatro" "cero" "cuarenta" "cero" "si" (Body002)
Tip: giving them different names (for example Eje, Tapa, Base; shaft, cap, base) makes the
spelling test clearer. The Label is changed in the tree.

==============================================================================
1. SEARCH BY SPELLING
==============================================================================
Test idea: in a list of objects, reach a specific one without saying
"avanzar" (next) many times.

1.1  Inside a list of objects
     Say: banco de trabajo -> diseño de pieza -> cortar -> cortar cilindro por medidas
           (cut -> cut cylinder by size)
           (five values) -> the list of bodies appears.
     Say:  "buscar por deletreo" (search by spelling)
     Spell the name of the object in the list, for example TAPA:
           "te" "a" "pe" "a"   and then "okey"
     Expected: the box jumps to the closest object, it is highlighted in 3D and the
     status names up to 2 alternatives. "okey" picks it.
     Variants to test:
       [ ] "deletrear"  or  "buscar"  (alone, without "por deletreo")
       [ ] spell only the beginning ("ta")
       [ ] deliberately mistake a neighboring letter (be for de) and see if it still finds it
       [ ] say "borrar" (delete) during the spelling and correct
       [ ] "cancelar" inside the spelling: the list must stay open
       [ ] letters with an anchor word: "te de taza", "pe de pato"
     What to look at: that after closing the spelling the list still responds to
     "avanzar" and "okey" (the voice must return to the list box).

1.2  Outside a list
     Say (in any context): "buscar por deletreo"
     Spell a name. Expected: it asks "¿Es ...?" (Is it ...?)
       [ ] "si" (yes)  -> it is left selected and centered on screen
       [ ] "no"  -> it offers the next most similar (up to 3)
       [ ] "cancelar" -> ends without choosing

==============================================================================
2. TECHDRAW BY VOICE (the scissors drawing, phase 4 of the guide)
==============================================================================
Requirement: a document with a solid object (the box or the scissors from the guide) and
a page: banco de trabajo -> dibujo tecnico -> pagina -> plantilla ->
(open ASME, siguiente x5, okey).
(workbench -> technical drawing -> page -> template)

2.1  Create a view
     Say: subir -> vistas -> "vista de objeto" (views -> object view)
     Expected, in this order:
       [ ] object list: "buscar por deletreo" or "avanzar" + "okey"
       [ ] direction: "isometrica" (others: frontal, superior, derecha,
           izquierda, trasera, inferior; or arriba/abajo + okey)
       [ ] scale: "uno coma veinticinco enter"
       [ ] X: "uno cero cinco enter"      Y: "uno seis cero enter"
     Expected: the view appears on the page at that position and scale.
     Variants: other directions; scale "cero coma cinco".

2.2  Change a view already created (each one asks which view if there are several)
       [ ] "direccion de vista"  (view direction) -> choose "frontal"
       [ ] "escala de vista"     (view scale) -> "dos enter"
       [ ] "posicion de vista"   (view position) -> X "cinco cero", Y "cinco cero"
       [ ] "proyeccion de pagina" (page projection) -> "tercer angulo" and then "primer angulo"
     Synonyms to test: "cambiar direccion", "cambiar escala", "colocar vista",
     "tipo de proyeccion".

2.3  Symmetry axis   (needs the page open on screen)
     Say: subir -> lineas -> "eje de simetria" (lines -> symmetry axis)
       [ ] choose view, "horizontal", "origen"  (or "centro")
     Expected: a center line crossing the view. If FreeCAD says it did not create
     the axis, open the page with a double-click and repeat. This is the riskiest
     command: it uses TechDraw's graphical API.
       [ ] also try "vertical" and "centro"

2.4  Overall dimensions
     Say: subir -> cotas -> extension -> "cotas totales" (dimensions -> extension -> overall dimensions)
       [ ] choose view. Expected: two dimensions (length and height) outside the figure.
     Synonyms: "cota total", "medidas totales", "largo y alto".

Idea for 2: reproduce the drawing from the guide (docs/es/voice-scissors-guide.md, steps 42-47)
and compare it with docs/ejemplo-tijeras/tijeras_dav.png.

3. EXPORT FOR 3D PRINTING
==============================================================================
Say: archivo -> proyecto -> "impresion 3d"   (or "preparar impresion",
      "exportar para impresion", "impresion tres de")
      (file -> project -> 3D printing; prepare printing; export for printing)
Expected:
  [ ] no selection: exports everything visible that is solid; warns if it skips
      objects that are not solids (a sketch, for example)
  [ ] format: "3mf" / "stl" / "obj" (or arriba/abajo + okey)
  [ ] folder: "aqui" (here, the same one) or "otra" (other, browser)
  [ ] name: "sugerido" (suggested), or "deletrear" (spell) and spell (e.g. "pe i e ce a" for PIEZA)
  [ ] if the file already exists: asks for "sobrescribir" (overwrite)
  [ ] at the end it prints the size in mm (x by y by z)
Test idea: export as STL, open the file in the slicer (Cura, Prusa,
Bambu) and check that the size matches the one DAV said.
Also try: selecting only one part (with "buscar por deletreo" or by hand)
and exporting only that one.

4. COLOR AND MATERIAL BY VOICE
==============================================================================
They work in any workbench. They apply to what is selected; if nothing is
selected, they open the object list (avanzar / buscar por deletreo).

4.1  Color
     Say: "cambiar color"  (change color; synonyms: "pintar objeto", "pintar pieza",
           "colorear objeto", "elegir color", "color de objeto")
       [ ] "rojo" (red)  -> the object looks red
       [ ] choose with arriba/abajo + okey
       [ ] with two objects selected at once
       [ ] on a Part Design body (its last operation is painted too)
     Colors: rojo, naranja, amarillo, verde, celeste, azul, violeta, rosa,
     marron, negro, blanco, gris (red, orange, yellow, green, light blue, blue, violet,
     pink, brown, black, white, gray).
     NOTE: the color was only verified headless (there is no view); this is the first
     real test.

4.2  Material
     Say: "poner material"  (set material; synonyms: "elegir material", "material de pieza",
           "material del objeto", "usar material")
       [ ] "aluminio", "acero", "inoxidable", "cobre", "laton", "pla", "madera"...
           (aluminium, steel, stainless, copper, brass, PLA, wood)
       [ ] the object changes appearance
       [ ] check in the tree: the object's ShapeMaterial property
     DO NOT confuse: "cambiar material", "asignar material" and "material" open the
     native FreeCAD dialog, which is not driven by voice (they stay the same).

Idea for 4: paint each scissors part a different color and give it a
material (blades steel, handles plastic, bolt stainless steel) and look at the
assembly.

5. IMPORT IMAGE (Draft and Sketch)   [STILL UNCOMMITTED]
==============================================================================
Setup: have a PNG or JPG in a folder (a photo of an object, a scanned
drawing, a screenshot).

5.1  Draft
     Say: banco de trabajo -> draft -> "importar imagen" (import image)
     (synonyms: "imagen de referencia", "imagen de fondo", "traer imagen")
       [ ] plane: "XY" (or arriba/abajo + okey)
       [ ] browser: choose the file (it only shows .png .jpg .jpeg .bmp)
       [ ] width: "ochenta enter"
       [ ] "¿centrada en el origen?" (centered on the origin?): "si"  and then repeat with "no" + X/Y
     Expected: a plane with the image, correct proportion, on the chosen plane.
     Try the three planes: XY, XZ, YZ.

5.2  Sketch
     Say: banco de trabajo -> croquis -> (new sketch and stay editing it) ->
           "importar imagen"
       [ ] picks the file and the width: the image stays behind the sketch
       [ ] draw a line on top: it must be visible (the image does not cover it)
       [ ] with no sketch in edit mode: it must show the list of sketches
           ("avanzar"/"buscar por deletreo")
     Test idea: import the photo of a part and trace its outline with
     lines by voice.

5b. SKETCH CONSTRAINTS THAT PREVIOUSLY NEEDED THE MOUSE   [STILL UNCOMMITTED]
==============================================================================
Setup: a sketch with 3 elements: a nearly horizontal line, a nearly
vertical one and a circle (the sketch is chosen from a list; the elements by number,
from 1, in the order they were drawn).
Path: banco de trabajo -> croquis -> restricciones -> geometricas
(workbench -> sketch -> constraints -> geometric)

  [ ] "horizontal vertical"  -> sketch, line number. Expected: it becomes
      horizontal if it is wider than tall, vertical if not. On a circle it must say
      that it is for lines only.
  [ ] "bloquear" (lock; or "fijar posicion") -> sketch, element and point ("inicio" (start),
      "final" (end) or "centro" (center)). Expected: the point is fixed where it was. On a circle
      it does not ask for the point (it uses the center).
  [ ] "coincidente unificado" (unified coincident) -> same as "coincidente": two elements and their points.
  [ ] "modo referencia" (reference mode; or "alternar conductora") -> first create
      a dimension (path: restricciones -> radio, etc.). It says the constraint number on
      screen; expected: it becomes "de referencia" (reference); repeating it makes it "conductora" (driving) again.
  [ ] "activar restriccion" (activate constraint; or "alternar activa") -> number of any
      constraint. Expected: it is deactivated; repeated, it is reactivated.
  Errors to provoke: a number that does not exist; in "modo referencia" choose a
  constraint that is not a dimension (it must reject it).
Test idea: draw a loose rectangle by voice, do "horizontal vertical"
on each side, fix a corner with "bloquear" and dimension with "radio"/"dimensión".

5c. ASSEMBLY AND SHAFTS BY VOICE   [STILL UNCOMMITTED]
==============================================================================
They used to be native FreeCAD commands that ask for the mouse. Now everything is spoken. They were
verified with simulated answers in FreeCAD 1.1 headless (the 13 joints, the new
part, the bill of materials, grounding and the structure of the exploded view);
they still need testing with voice and with the real window.
Setup: two bodies with one cylinder each (see SETUP) and an assembly:
  banco de trabajo -> ensamblaje -> "nuevo ensamblaje"; then "insertar vinculo" twice
  (avanzar / okey to choose each body).
  (workbench -> assembly -> new assembly; insert link)

5c.1 Joints from the Assembly level  (path: banco de trabajo -> ensamblaje)
  Each one asks for the two parts (avanzar / okey) and the face of each.
  [ ] "ensamble fijo"            [ ] "bisagra"               [ ] "junta deslizante"
  [ ] "junta cilindrica"         [ ] "junta esferica"        [ ] "junta paralela"
  [ ] "junta perpendicular"
  [ ] "junta por distancia"  -> also asks for the distance (mm)
  [ ] "junta por angulo"     -> also asks for the angle (degrees)
  [ ] "junta de engranajes"  -> asks for two radii (mm)
  [ ] "junta de correa"      -> asks for two radii (mm)
  [ ] "junta de tornillo"    -> asks for the pitch radius (mm)
  [ ] "junta de cremallera"  -> asks for the pitch radius (mm)
  (fixed joint, hinge, slider joint, cylindrical joint, spherical joint, parallel joint,
  perpendicular joint, distance joint, angle joint, gear joint, belt joint, screw joint, rack joint)
  Expected: the joint appears in the tree (Joints folder) and "resolver" (solve) moves the parts.

5c.2 The same joints through the «junta» folder  (path: ensamblaje -> junta -> ...)
  They used to enter the native command (clicks on the faces); now they do the same as
  5c.1. Test at least three, for example:
  [ ] "junta" -> "esferica"      [ ] "junta" -> "distancia"     [ ] "junta" -> "tornillo"
  Expected: NO FreeCAD task panel appears; it asks for the parts by voice.

5c.3 Ground part  ("fijar pieza", "fijar", "anclar")
  [ ] It says which part to ground (avanzar / okey). Expected: "GroundedJoint" appears in
      Joints. Before, it toggled what was selected with the mouse.

5c.4 New part  ("nueva pieza", "crear pieza")
  [ ] Expected: an empty part is created ("Pieza", "Pieza002"…) with its Body and a
      sketch with a circle, it is inserted in the assembly and its Body becomes
      active. It does NOT ask to save the document or another file (unlike the native
      command). Repeat it: the name is not overwritten.

5c.5 Bill of materials  ("lista de materiales", "tabla de materiales")
  [ ] Expected: "Bill of Materials" is created with the columns index, name,
      description, file and quantity; the sheet opens. No column panel.
      Check that the quantity counts repeated parts correctly.

5c.6 Exploded view  ("vista explosionada", "explosionar")
  [ ] Asks for the separation in mm ("treinta enter"). Expected: "Exploded View" appears
      with a radial movement. THE MOST DOUBTFUL: that the view looks exploded
      (it is shown with a double-click on "Exploded View" in the tree, or from its menu) and that
      "mas distancia" (more distance) separates more. Only the structure of the objects was verified.
  [ ] With an empty assembly it must say there are no parts.

5c.7 Shaft generator  (path: diseño de pieza -> administrar -> "generar ejes")
     (part design -> manage -> generate shafts)
  [ ] Asks for the number of sections (1 to 12) and, per section, the length and the diameter.
      Test: 3 sections: 40 x 20, 30 x 30, 20 x 16. Expected: a Body "Eje" 90 mm
      long along the Z axis, with a single valid solid (volume 37,793 mm3).
  [ ] Cancelling halfway must leave nothing created.
  Note: it no longer calculates forces or stresses like the native wizard; it only builds the geometry.

5c.8 Revolution by angle  ("revolucion por angulo", "girar perfil")
  [ ] Chooses the sketch from a list (avanzar / okey) and asks for the angle; it is no longer necessary
      to select it beforehand with the mouse. Try 360 and 180, and a profile that crosses the axis
      (it must warn with an error and leave no broken objects).

Still NOT by voice (they keep opening FreeCAD's panel or dialog):
  - "simulacion" (simulation; motions panel and timeline)
  - "preferencias" (preferences) of the Assembly workbench (settings dialog)

==============================================================================
6. WHAT IS MOST LIKELY TO FAIL (look at this first)
==============================================================================
  1. "buscar por deletreo" inside a list: that the voice returns to the list when
     finished. If it stays "mute", it is the transition between boxes.
  2. Symmetry axis and dimensions: they require the page drawn on screen.
  3. Color: first test with the real view (DiffuseColor per face).
  4. That the recognizer distinguishes similar phrases: "escala de vista" /
     "posicion de vista" / "direccion de vista". If it confuses them, note what it heard.
  5. Image: the proportion when the PNG is read with PySide inside FreeCAD.
  6. Exploded view (5c.6): that it looks exploded with the real window.
  7. Joints: that "junta esferica" said in one go and "junta" -> "esferica" do the
     same thing; if the recognizer confuses "junta" with another word, note what it heard.
  8. New part (5c.4): that the active Body allows modeling right away without extra steps.

If something fails, send me: what you said, what DAV heard (the text the box shows)
and the message that appears in the FreeCAD console (the ones that start with [DAV]).
