TAREA PARA ALEX — Pruebas selection/ + documento Word
=====================================================
Fecha límite: mañana
Código: hecho por Ellui. Vos probás y documentás.

PASO 0 — Pull y abrir FreeCAD
-----------------------------
  git pull origin Pruebas
  Doble clic en iniciar_dav.bat   (o .\iniciar_dav.bat desde la raíz del repo)

  Eso instala el módulo DAV y deja selection/ listo en la consola.
  No hay que editar rutas ni variables.

PASO 1 — Sketcher (5 herramientas mínimo)
-----------------------------------------
  Archivo > Nuevo
  Workbench Sketcher. Crear UN sketch con:
    [ ] Point
    [ ] Line
    [ ] Circle
    [ ] Rectangle
    [ ] Arc

PASO 2 — Consola Python (todo en uno)
-------------------------------------
  Ver > Panels > Python console

  Copiá y pegá (sin cambiar nada):

    from scr.gui.dav_commands import RunAlexSelectionPrueba
    selector = RunAlexSelectionPrueba()

  Para ciclar selección, pegá varias veces:

    selector.SelectOther = True

PASO 3 — Opcional 3D
--------------------
  Crear un Pad/box. En consola:

    from console_helpers import RunCreateObjects, PrintObjectTree
    RunCreateObjects("Pad", Is3D=True, Language="es")
    PrintObjectTree()
